# Crypto Sentiment Analysis

## Overview
This project analyzes the relationship between Bitcoin market sentiment and trader performance using historical trading data and Fear & Greed Index data.

## Technologies Used
- Python
- pandas
- matplotlib

## Analysis Performed
- Data cleaning
- Timestamp conversion
- Dataset merging
- Sentiment vs profitability analysis
- Trade activity analysis
- Top trader identification
- Data visualization

## Key Insights
- Highest average profitability occurred during Greed sentiment.
- Most trading activity occurred during Fear periods.
- Trading activity and profitability showed different trends.

## Files
- analysis.ipynb
- historical_data.csv
- fear_greed_index.csv
